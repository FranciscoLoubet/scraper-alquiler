3.Crear un Issue y un Branch para tu tarea:Cada vez que te asignen una tarea pequeña.Vayan a la pestaña Issues en GitHub y creen uno (ejemplo: #1 Create scraper for ZonaProp).En la terminal, parate en dev, traé lo último que subió tu compañero y creá tu rama para la tarea específica:Bashgit checkout dev
git pull origin dev
git checkout -b feature/scraper-zonaprop
4.Trabajar y guardar cambios:Durante el día mientras programás.Guardá tus avances localmente con mensajes claros y subilos a GitHub:Bash# Ver qué archivos modificaste
git status

# Preparar los archivos
git add .

# Guardar con un mensaje descriptivo
git commit -m "Agrega extractor de precios en ZonaProp"

# Subir tu rama a GitHub
git push -u origin feature/scraper-zonaprop
5.Abrir un Pull Request (PR):Al terminar la feature.Entrá a la página de GitHub de tu proyecto. Verás un botón amarillo que dice Compare & pull request. Hacé clic ahí.IMPORTANTE: Cambiá la rama base. Configuralo para mergear base: dev $\leftarrow$ compare: feature/scraper-zonaprop (¡nunca directo a main!).En la descripción escribí: Closes #1 (poniendo el número del Issue). Esto cerrará la tarea automáticamente cuando se apruebe.Asigná a tu compañero como Reviewer.6.Revisar y Mergear:Tu compañero hace este paso.Tu compañero entra a la pestaña Pull Requests, revisa la pestaña Files changed y deja comentarios o correcciones si hace falta.Si está todo bien, hace clic en Approve y luego en Confirm merge.Borren la rama feature/scraper-zonaprop en GitHub usando el botón que aparece ahí mismo.
